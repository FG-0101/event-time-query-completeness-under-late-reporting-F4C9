Event-Time Query Completeness under Late Reporting
reproduction

Requirements
  CPython 3.14 on a POSIX system with the versions pinned in ENVIRONMENT.json
  (duckdb 1.5.5, matplotlib 3.11.2, numpy 2.5.3, pandas 3.0.5, pyarrow 26.0.0,
  scipy 1.18.1, statsmodels 0.15.0).  The package is self-contained: every input
  is included and no network access is used.

Command
  python3.14 -B reproduce.py

  The command copies code/, data/, results/, figures/ and tex/ into
  runs/<UTC timestamp>/ and runs seven stages there, in dependency order: the
  reporting-triangle delay build, the revision and vintage series, the two
  regression-discontinuity programs, the nowcasting evaluation, the report
  tables and figures, and the bounded-share sensitivity.  Each program runs
  under the numeric-thread policy of the release, with the OMP, OpenBLAS, MKL,
  VECLIB and NUMEXPR thread counts all set to 2 and a private MPLCONFIGDIR, so
  that floating-point results are reproducible.  The shipped tree is never
  modified.  Each stage has a 120-second CPU limit; use --cpu-limit 3600
  if the machine is slow.

Comparison
  Every result file under runs/.../results/ is compared with expected.json,
  which holds the corresponding reference result.  This follows the policy the
  paper states: query timings and low-order floating-point solver differences
  may vary, while integer counts, scientific values at printed precision and
  query memberships are the comparison targets.  Execution records, environment
  fields, absolute paths and wall-clock timings are dropped before comparison;
  integers and text must then agree exactly and floats agree to a relative 1e-9.
  A CSV is compared as a value-sorted row multiset, because row order is not
  part of the contract.  PASS and CHECK.json indicate a full match.

Excluded from the comparison
  The release also writes execution records, which are not scientific results
  and are excluded by name: reproduction_logs/02_build.py.log,
  03_revisions.py.log, 04_rd.py.log, 04b_rd_robust.py.log, 05_nowcast.py.log,
  06_report.py.log, 07_bounded_rd.py.log, 07_bounded_final_layout.log,
  environment.json and execution.json.  The per-step logs carry pandas
  positional index columns, and environment.json and execution.json are
  environment and wall-clock timing records.  figures/fig_delays.pdf,
  fig_vintages.pdf, fig_migration.pdf and fig_nowcast.pdf, and the generated
  tex/ tables (macros.tex, tab_platforms.tex, tab_vintage.tex, tab_spikes.tex,
  tab_rd.tex, tab_rdplat.tex, tab_robust.tex, tab_nowcast.tex and
  bounded_rd.tex), are regenerated by 06_report.py and 07_bounded_rd.py but are
  renderings rather than result files; the numbers they render are compared
  through results/, so a PDF coordinate or a table layout cannot mask or fake a
  numerical change.

Expected counts
  37 monthly complete-product reporting triangles; 42,535,834,864 statements in
  the retained snapshot, of which 42,521,587,902 are valid; 20 compared result
  files under results/.

Data
  data/derived/ holds the 37 monthly reporting-triangle reductions
  (tri_YYYY-MM.parquet) and the checksums.csv register.  data/archive_snapshot_lock.json
  records the retained publisher checksums.  The acquisition step that would
  rebuild these from the raw daily archives is not part of this package.
  Sources and terms are in SOURCE.txt and LICENSE.txt.

Files
  reproduce.py      the driver
  expected.json     expected result content, keyed by run-relative path
  code/             the analysis programs and the run_step.py environment shim
  data/             the reduced inputs
  RESULTS.tsv       paper item to program, line, output and input
  ENVIRONMENT.json  the recorded release environment
